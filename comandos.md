# HTML
No html usei um certo comando chamado onclick:
```html
<button onclick="jogar('pedra')">Pedra</button>
<button onclick="jogar('papel')">Papel</button>
<button onclick="jogar('tesoura')">Tesoura</button>
```
ele basicamente executa o codigo do js de onde o usuario clicar.

### ID
O id foi somente pra mostra o resultado:
```html
<p id="resultado"></p>
```


### Link
O link usei pra importa o Css:
```html
<link rel="stylesheet" href="style.css">
```
### script
Utilizado para linka o script.js pro html (backend)
```html
<script src = "script.js"> </script>

```

## JavaScript
No java script usei um comando diferente do `console.log`, ele é o :
```html
document.getElementById("resultado").innerHTML
```
ele é do html, serve pra mostrar no html o resultado.
